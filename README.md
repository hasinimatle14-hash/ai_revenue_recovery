# AI Revenue Recovery Agent

An AI-powered system that helps merchants recover revenue lost from failed or abandoned payments.

## What It Does

- Analyzes payment failures
- Diagnoses failure reasons
- Selects suitable recovery strategies
- Manages safe payment retry decisions
- Sends recovery actions/reminders
- Supports human review for uncertain cases
- Detects system and recovery anomalies
- Provides governance and audit monitoring
- Includes a Recovery Control Center and System Pipeline
- Uses simulated payment data for safe demonstration

## Tech Stack

- React + TypeScript
- Python + FastAPI
- AI/Agent-based decision pipeline
- Vercel
- Render
- GitHub
